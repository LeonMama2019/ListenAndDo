# Stage5：いつもの準備と追加の用事

2026-10-06の構想決定。実装はまだ行わない。

## 決定した方向

- 箱の中に、物ごとの定位置を作る。本・ペン・消しゴムなどをそろえる。
- 箱をそろえる共通ルールに加え、音声で追加の用事を指示する。本を棚へ返す、お使いで物を届けるなど。
- 箱には時々足りない物がある。追加の用事だけで終わらず、箱を確認して不足を補う。
- 不足品が隠れている負荷も採用する。
- 上達の観察では、追加の用事の抜けと、いつもの準備の抜けを分ける。

## 隠す負荷の段階案

1. 机の上に見えている。
2. 本の陰から一部だけ見える。
3. 引き出しを開けると見つかる。
4. 2〜3か所の候補から探す。

最初は隠し場所を固定し、慣れたらランダムにする。まずは追加の用事を増やさず、隠す負荷だけを加えて難しさを比較する。

## 先に提案したレベル構成（実装前に再確認）

| レベル | 箱の準備 | 追加の用事 |
|---|---|---|
| 1 | 3つの定位置に置く | なし |
| 2 | 足りない1つを補う | なし |
| 3 | ランダムに足りない1〜2つを補う | なし |
| 4 | 足りない1つを補う | 1つ |
| 5 | 足りない1〜2つを補う | 2つ |
| 6 | 用事の後に不足を確認する | 2つ |
| 7 | 箱の物を用事に使い、戻す | 使った物を戻す用事 |
| 8 | 不足・使った物・余分な物を整理する | 複数の用事 |

隠す負荷をどのレベルへ入れるかは未確定。

## 操作・記録の提案

- 最後は本人が「じゅんびできた！」を押して完了を申告する。
- 追加の用事の抜け、箱の不足、定位置の誤りを分けて記録する。
- 不足に気づくまで、探す時間、見つけた物を箱へ戻せたかを分けて観察する。
- 「不足に気づいた時刻」は直接分からないため、チェック開始など観測できる操作を定義してから実装する。
