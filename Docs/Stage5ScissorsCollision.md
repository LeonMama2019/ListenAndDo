# ハサミの透明部分を除外する重なり判定

scissorsのSpriteが関わる組み合わせだけ、画像のアルファ値で判定します。
アルファ26/255以上の画素を横方向の連続区間として読み取り、同じ区間を縦に結合してキャッシュします。
刃の横の余白・持ち手の穴を含め、透明部分に他の物の矩形が入っても衝突しません。
画像の回転・RectTransform・preserveAspectに合わせて判定用区間を変換します。
他の物同士は従来のメッシュ判定を維持しています。
既存の重なり許可ルール、収納範囲の判定、クリック操作は変更していません。
ハサミ画像だけRead/Writeを有効化。画像の描き直し・Scene・ScriptableObjectの変更はありません。
ハサミの画像をSprite Atlasに含めた場合、またはRead/Writeを無効化した場合はエラーを出して従来判定へ戻します。

実際のハサミSpriteのアルファを再構築し、全画素の一致・透明領域の許可・本体部分の拒否を確認。
C#構文確認済み。Unityでの実操作・WebGL実行は未確認です。
