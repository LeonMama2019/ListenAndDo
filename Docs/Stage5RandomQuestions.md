# Stage5 共通の収納先別リスト

## Objects
ID・画像・名前の音声だけを登録します。レベルは不要です。

## Place Objects
Pencase・Odougu・BookStandごとに、所属するObjectsのIDを1回だけ登録します。
同じIDを複数の収納先に重複登録しないでください。

初回は、Stage5シーン内の実際の子オブジェクトと画像を照合して自動で引き継ぎます。
Inspectorはプレビューシーンを使うため、編集中のシーンを切り替えません。
編集中のシーンに未保存の変更がある場合は、その変更を保存してからアセットを選択してください。
自動照合できない画像は、Objectsを削除せず所属リストに手動登録できる状態で残します。
作成済みの所属リストは、以後ユーザーの編集を尊重して自動生成し直しません。

## Levels
- Level：1〜8の出題レベル。
- Places：今回扱う収納先を複数選択。
- Question Count：問題数。
- Min / Max Object Kinds：出題する種類数。
- Quantity Overrides：単品以外の数量候補だけを追加。

選択したPlacesの所属IDを集めて候補にします。
単品は自動で候補になるため、各レベルで同じIDを並べ直す必要はありません。
例：Pencase + BookStandを選ぶと両方の所属が対象です。
鉛筆2本を混ぜる場合だけ、Quantity Overridesに鉛筆のID、Count 2、「2本」の音声を登録します。
その場合は1本か2本を抽選します。
質問形式のObject Idsを指定すれば、その中からさらに対象を絞ります。

## 移行と入力保持
入力済みアセットは直接書き換えていません。
旧Targetsは非表示で保持し、2個以上の指定と音声をQuantity Overridesへコピーします。
重複した同じID・個数はまとめ、未設定の音声が別の旧設定にあれば補います。
異なる音声が競合した時は勝手に消さず警告します。
旧Targetsの単品候補、および未入力のCount 0は、共通候補の単品に置き換わります。
Level 0や、複数個の数量音声未設定など、その他の入力値は勝手に変更しません。

## 音声
名前 → 数量（複数個の時だけ）→ 質問形式の続き。
複数種類は接続音声「と」でつなぎ、聞き返しても抽選し直しません。
質問形式のLevelは使用開始レベルです。
