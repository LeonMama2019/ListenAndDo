# Stage6：積み木を追加し、別の視点からの形を考える

2026-10-06の構想。実装はまだ行わない。

## 決定したテーマ

積み木の構造に1個追加した時、横など別の方向から見たらどんな形になるかを考えるゲーム。「ここに一つ重ねると、横から見たらどうなる？」を中心にする。

## 提案したゲームの流れ

1. 斜めから見た積み木の構造を表示する。
2. 音声で追加位置を指示する。例：「赤い積み木の上に、1個置いてね」。
3. 子どもが置く場所を選ぶ。
4. 「右から見ると、どの形になる？」など、別の視点の見え方を質問する。
5. 選択肢から見え方を選ぶ。
6. 回答後、実際に回して見せ、形を確認できるようにする。

追加位置を子どもが選ぶ操作、質問の言い方、選択肢数、回転による答え合わせは提案段階。レベル構成とともに実装前に詳細を確定する。

## 実装方針の候補

- 画面全体を3Dにする必要はない。既存の2D UIの中に、3Dの積み木表示を組み合わせる構成を提案した。
- 3Dなら、積み木の追加位置から各方向の正確な見え方を生成しやすい。
- 固定された問題だけなら、対応する視点の絵を用意する2D方式も可能。
- 回答前には視点を固定し、想像して答える課題とする案。
- 見せる情報から正解を一つに決められる構造にする。隠れた積み木を根拠なく推測させない。

## 観察したい処理

音声の位置指示の理解、積み木を追加した後の構造の保持、視点の変換、選択した見え方との比較。能力の測定・訓練効果を断定するものではない。
