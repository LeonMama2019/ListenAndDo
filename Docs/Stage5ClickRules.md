# Stage5 クリック操作

| 状態 | クリック先 | 動作 |
|---|---|---|
| 何も持っていない | 机上の初期アイテム | 持つ（向きを変えない） |
| 持っている | DeskArea | 置く |
| 机に置いた直後 | 置いたそのアイテム | その場で1回転分だけ回す |
| 回転後 | 同じアイテム | 再び持つ |
| 何も持っていない | 収納済みアイテム | 持つ（向きを変えない） |
| 持っている | 正しい収納先 | 収納する |
| 持っている | 別の物の上 | カーソル位置の収納先／DeskAreaとして処理 |

回転量は鉛筆・赤鉛筆180度、消しゴム・お道具箱の物・本90度。
置いた物ごとに次回クリックの状態を記憶します。
別の物を操作しても、置いた直後の物の次回操作は回転です。

ペンケース・お道具箱の初期方向は、各回転量で整えられる方向に限定します。
本立ては引き続き左右のクリックで空きへ収納。
はみ出し・禁止されている重なり・間違った収納先は収納できず、持ったままです。
回転操作も配置記録へ保存します。
