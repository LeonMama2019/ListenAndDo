# Stage6 動作確認

Stage6ControllerをCanvasに接続。コピー元のStage5PrototypeはStage6シーン内のみ無効化。Stage5のシーン・コード・素材は変更しない。

## 遊び方

1. Stage6を選び、レベルを開始する。直接シーンを再生した場合はLv1。
2. 指示音声が終わってから、散らかった物をタッチして持つ。
3. 収納先をタッチして置く。収納の種類・はみ出し・重なりを判定する（Stage5と同じ重ね置きの許可とハサミの透明部分判定）。机の上では最初のクリックで回転、次で置く。
4. 全部を片付けてから、届ける物を収納から取り出す。
5. Class1button／Groundbuttonで移動。Panelは非表示になり、選んだ場所が表示される。持っている物は維持される。
6. 指定された人物をタッチして渡す。別の物・相手には渡せず、持ったままになる。
7. 部屋の「もどる」で作業画面へ戻る。複数件は1件ずつ取りに戻る。
8. 全件正しく渡し、残りの物もすべて正しく収納されるとCheck表示と効果音。3秒後に次の問題へ。全問題終了でLevelResultに移動し、結果とレベル完了を保存する。

場所指定なしは人物を2部屋全体で重複させない。届けた物は残りの収納判定から除外する。

## 確認項目

- Lv1：片方の収納だけ散らかる。片付け前の受け渡しはできない。
- Lv2：片付けた側とは別の収納から持ち出す。
- Lv3：両収納を片付ける。
- Lv4：各場所3人の中から選ぶ。
- Lv5：場所音声がなく、人物を探す。
- Lv6〜8：2〜3件の完了前にCheckが出ない。渡す順は自由。
- 物を持ったまま往復しても消えない。
- 再生ボタンで同じ指示を聞き直せる。聞き直し中は操作をロック。
- 作業画面のBackは既存の確認パネルを開き、YesでStage6のLevelMenuへ戻る。
- 複数の鉛筆は同じ素材IDで1本ずつ扱い、未登録の粘土も片付け対象に含める。

## 検証状況

シーンの参照、Controllerの接続先、8レベルの設定とシーンのアイテム対応を静的に確認。Unity実行環境がないため、コンパイル・実際のクリック・音声の聞こえ方は未確認。
2026-10-19確認時点で、音声の参照はStorage Voicesの筆箱・お道具箱だけ空欄。全音声が設定されるまで、開始時にエラーを表示して出題しない。音声ファイルの内容がラベル通りかは試聴が必要。
